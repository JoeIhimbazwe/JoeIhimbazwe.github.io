01 · The idea

Every AI leaves a fingerprint

Different AIs write in slightly different ways. They like different words, different sentence styles and different layouts. Our program learns these small habits, like a detective learning someone's handwriting. The big question: can it tell not only the company, but the exact version, like GPT-3 versus GPT-4?

The 12 writers

Two kinds of AI model

Base models were only trained to continue text, like a super-powered autocomplete.

Chat models were also trained to talk like a helpful assistant. Most companies make both kinds.

We used 500 texts from each writer: 6,000 texts in total, from the free RAID dataset.

02 · How it works

Six steps, all on free tools

Everything runs in Google Colab with a free GPU. Training the smart model takes about 4 minutes.

  1. CollectDownload labelled texts from RAID. Skip "attacked" texts that were changed to trick detectors.
  2. BalanceTake exactly 500 texts per writer, so the program can't win by always guessing the most common one.
  3. Split80% of texts for learning, 20% hidden as a final exam the program has never seen.
  4. BaselineA simple model counts which words each text uses (TF-IDF + logistic regression).
  5. Fine-tuneRoBERTa, a model that already reads English well, learns our task in 3 rounds.
  6. AnalyseRepeat 3 times with different random splits, then study which writers get mixed up and why.
03 · Results

Four things we found

Each finding below shows the result in plain words on the left and the evidence on the right.

Finding 1 · Accuracy

The smart model is right almost 9 times out of 10

RoBERTa beat the simple word-counting model by 14 points, and the result barely moved between runs (± 0.8), so it is stable and not luck.

The black lines on the bars show how much the score changed between our 3 runs.

Accuracy on 1,200 hidden test texts
Average of 3 runs with different random splits
Runs with seeds 1, 2, 3 · baseline 73.4 / 74.1 / 74.3 · RoBERTa 88.8 / 87.2 / 87.7
Finding 1 · Per writer

Some AIs are easy to spot, some are hard

  • Easiest: GPT-3 and human texts, both close to perfect.
  • Hardest: mistral-chat. It writes like a "general chatbot", so it gets mixed up with other chat models.
  • RoBERTa improved almost every writer. The biggest jump was cohere, from 0.70 to 0.97.

The score here is called F1. It goes from 0 to 1, and 1 means perfect.

Score per writer: simple model → RoBERTa
F1 score, one run (seed 42). Grey dot = simple model, coloured dot = RoBERTa.
Finding 2 · Mistakes

Chat AIs sound alike, whoever made them

When the program is wrong, it almost always confuses two models of the same type: a chat model with another chat model, or a base model with another base model.

The company does not matter. Mistral and mistral-chat come from the same company, but the program almost never mixes them up.

The chance that this pattern happened by luck is about 1 in 1022. In science, anything under 1 in 20 counts as real.

Finding 3 · Text length

It needs about 100 words

We gave the trained model only the first few words of each test text. At 100 words it is right 81% of the time. Under 50 words, it is wrong more often than right.

So for a tiny text like "I like you", nobody can reliably say which AI wrote it. Even with 5 words, though, it is still about 4 times better than guessing.

Accuracy goes up as the model reads more words
RoBERTa on the 1,200 test texts, cut after N words (seed 42)
Finding 4 · Formatting

The layout gives it away

"Formatting" means how a text looks: where the new lines are, how long the paragraphs are, whether there are lists. We found this by accident, when a bug removed all the line breaks and the score crashed.

A model trained without formatting still reaches 78.3%, so the words alone carry a lot. But line breaks and paragraphs add another 9 points.

Someone could fool a detector just by changing the layout. A good detector should learn from texts both with and without formatting.

So most of RoBERTa's lead over the simple model comes from formatting.
04 · What's next

Testing today's AIs

RAID is one to two years old. Newer models are not in it, so we are building our own data. We give new models the exact same prompts RAID gave ChatGPT, so the only difference is who wrote the answer.

In progress

Gemini, two versions

Collecting 500 texts each from gemini-3.5-flash-lite and gemini-3.1-flash-lite through Google's free API. Can the program tell two neighbouring versions apart?

Planned

Gemma, two sizes

Gemma 4 26B and 31B are open models from the same family in two sizes. Does a bigger model write differently from a smaller one?

Planned

GPT-4o and Claude

These need a small paid API budget. Then we test whether "chat models sound alike" still holds for the newest models.

  • Repeat Findings 3 and 4 three timesLike Finding 1, so we can report an average and a spread instead of one run.
  • Check how RAID groups GPT-3Its GPT-3 may have had some assistant training. If it is really a chat model, Finding 2 needs to be redone.
  • Check how RAID cleaned each model's textIf line breaks were changed during collection, part of Finding 4 may come from the data, not the AI.
  • Make Gemini a fair testGemini writes with markdown like **bold** and ## headings. We will test it with and without formatting, so it isn't spotted by layout alone.
05 · Words to know

The jargon, in plain words

New to machine learning? These are all the technical words used on this page.

Dataset
A big collection of examples a computer learns from.
Balanced
Every group has the same number of examples.
Train / test split
Learning texts, and "exam" texts the model has never seen.
Accuracy
How many test texts the model got right, in percent.
Baseline
A simple first model. Better models must beat its score.
TF-IDF
A way to turn text into numbers by counting special words.
RoBERTa
A language model that already knows a lot of English.
Fine-tuning
Teaching an already smart model one new task.
Epoch
One full pass through all the learning texts.
Seed
The starting number for randomness. A new seed gives a new shuffle.
Mean ± spread
The average result, and how much it moves between runs.
Confusion matrix
A grid showing which writer gets mistaken for which.
F1 score
One score from 0 to 1 for how well a writer is recognised.
p-value
The chance a result happened by pure luck. Under 0.05 counts as real.
Base model
An AI trained only to continue text.
Chat model
An AI also trained to act like a helpful assistant.
API
A way for code to talk to an AI service directly.
Rate limit
The most requests a service allows per minute or per day.
GPU
A computer chip that makes AI training much faster.
Prompt
The question or instruction given to an AI.
